# БлокЛаб — редактор текстур для Minecraft PE

Нативное Android-приложение для рисования и подготовки текстур Minecraft Bedrock / PE. Интерфейс полностью на русском, работает офлайн и не запрашивает доступ ко всему хранилищу телефона.

## Что умеет

- Полотно 16×16, 32×32 или 64×64 пикселя; также можно открыть PNG до 256×256.
- Кисть, заливка, пипетка и ластик; сетка; отмена и повтор последних 24 действий.
- Палитра и выбор произвольного цвета по оттенку, насыщенности и яркости.
- Импорт PNG и текстур из `.mcpack` / ZIP через системный выбор файлов.
- Экспорт прозрачного PNG через Android «Сохранить файл».
- Сборка `.mcpack` с `manifest.json`, иконкой пакета и текстурой для выбранного блока (трава, земля, камень, песок, алмазная руда, дубовые доски или листья).
- Автосохранение текущего проекта на устройстве.

## Открыть в Android Studio

1. Откройте **корень репозитория** как Gradle-проект.
2. Используйте JDK 17 и Android SDK Platform 35.
3. Запустите конфигурацию `app` или выполните:

   ```bash
   ./gradlew assembleDebug
   ```

Готовый debug APK появится в `app/build/outputs/apk/debug/app-debug.apk`. Минимальная версия Android — 6.0 (API 23). APK для установки на обычный телефон подписывается debug-ключом; для публикации нужно собрать и подписать release-сборку собственным ключом.

## Скачать APK из GitHub Actions

Workflow **Android APK** собирает debug APK при push, pull request или вручную. В завершившемся запуске откройте **Artifacts → `blocklab-debug-apk`**.

## Установка `.mcpack`

В редакторе выберите нужный блок и нажмите **Экспорт .mcpack**. Сохраните файл, затем выберите **Открыть в Minecraft**. Если Android не предложит Minecraft, откройте файл `.mcpack` из «Загрузок» или передайте его через системное меню «Поделиться».

## Сборка и ограничения

Приложение использует только Android SDK и встроенные библиотеки Java/Android. Для импорта/экспорта применяются системные Storage Access Framework диалоги, поэтому разрешение на чтение всего хранилища не требуется. Код редактора находится в `app/src/main/java/com/pixelcraft/blocklab/`.
